## Pasting into Excalidraw

To convert any diagram in Excalidraw:
1. Open Excalidraw (or the VS Code Excalidraw extension).
2. Open the command palette or more tools menu and select **Mermaid to Excalidraw**.
3. Paste the Mermaid code from any `.mmd` file.
4. Insert into the canvas to edit or rearrange visually.
